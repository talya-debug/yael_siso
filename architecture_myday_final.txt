My Day — ארכיטקטורה סופית
============================

══════════════════════════════════════
העיקרון: My Day = מרכז העבודה היומי
══════════════════════════════════════

הכל קורה מפה. בת הצוות לא צריכה להיכנס לשום מקום אחר.
היא רואה את כל מה שצריך לעשות, מוסיפה משימות קטנות בשניה,
ומסמנת Done. הכל מסונכרן — לפרויקט, לגוגל, לכל מקום.

══════════════════════════════════════
שני סוגי משימות
══════════════════════════════════════

סוג 1: משימות פרויקט
- מגיעות אוטומטית מהפרויקטים (assigned_to = שלה)
- Done ב-My Day = Done בפרויקט = Done בגוגל
- לא צריכה להיכנס לפרויקט בשביל לסמן
- אם כל השלב הושלם → גבייה עוברת ל-pending_approval

סוג 2: משימות יומיומיות (My Notes)
- בת הצוות מוסיפה בעצמה
- הוספה = כתיבת שורה + Enter. הכי קליל שיש. בלי מודאל.
- פרויקט = אופציונלי (dropdown קטן, לא חובה)
- מסונכרנות לגוגל טסק ✅
- מופיעות ב-My Day בלבד (לא בתוך הפרויקט)
- Done = V בגוגל

══════════════════════════════════════
סנכרון — הכל מחובר
══════════════════════════════════════

משימות פרויקט:
  My Day ← שולף מ-tasks (assigned_to)
  Done ב-My Day → מעדכן tasks → מעדכן גוגל
  Done בגוגל → מעדכן tasks → משתקף ב-My Day + בפרויקט
  שינוי בפרויקט (assignee/date) → משתקף ב-My Day + בגוגל

משימות יומיומיות:
  נוצרות ב-My Day → נשמרות ב-daily_tasks → נשלחות לגוגל
  Done ב-My Day → מעדכן daily_tasks → V בגוגל
  Done בגוגל → מעדכן daily_tasks → משתקף ב-My Day

══════════════════════════════════════
לייאאוט — שני פאנלים
══════════════════════════════════════

פאנל שמאל (60%) — "My Tasks":

  Header:
  - ברכה: "Good morning, Adi"
  - תאריך: "Monday, May 26, 2026"
  - "You have 5 tasks today"
  - טאבים: Upcoming / Overdue (עם מספר)
  - "3/8 done" עם פס התקדמות

  משימות פרויקט:
  - כל משימה: ○ checkbox + שם + מרובע צבע פרויקט + שם פרויקט + due date + חץ →
  - "3 days late" באדום
  - "Today" בכחול
  - Done = V ירוק + קו חוצה + fade

  My Notes (למטה, תמיד גלוי):
  - כותרת: "My Notes"
  - Input inline: "Add a quick note or personal reminder..."
  - PRESS ENTER TO SAVE
  - רשימה של משימות יומיומיות עם checkbox
  - כל משימה: ○ + שם + (שם פרויקט אם נבחר)
  - Done = V + קו חוצה

פאנל ימין (40%) — "My Projects":

  כרטיסי פרויקט:
  - אייקון צבעוני (מרובע 48px) + שם פרויקט
  - "2 tasks due soon" / "4 tasks overdue" (באדום)
  - פס התקדמות צבעוני
  - לחיצה → נכנסת לפרויקט
  - רק פרויקטים שהיא מנהלת (default_assignee = שלה)

══════════════════════════════════════
שינויים בפרויקט — מה קורה
══════════════════════════════════════

יעל מוסיפה משימה עם assignee:
→ מופיעה ב-My Day של הבת צוות
→ נשלחת לגוגל טסק שלה

יעל משנה due_date:
→ מתעדכן ב-My Day + בגוגל

יעל מעבירה assignee:
→ נעלמת מ-My Day של הישנה
→ מופיעה ב-My Day של החדשה
→ מתעדכן בגוגל של שתיהן

בת צוות מסמנת Done ב-My Day:
→ Done בפרויקט
→ V בגוגל
→ אם כל השלב Done → גבייה pending_approval

בת צוות מסמנת V בגוגל (מהנייד):
→ Done במערכת
→ Done ב-My Day
→ אם כל השלב Done → גבייה pending_approval

══════════════════════════════════════
Admin — גם Dashboard וגם My Day
══════════════════════════════════════

Admin (יעל/קלואי) רואות בתפריט:
- Dashboard — סקירה כללית (KPIs, פרויקטים, משימות)
- My Day — העבודה היומית שלהן

שתי כניסות נפרדות. Dashboard = ניהול. My Day = עבודה.

══════════════════════════════════════
DB — מה משתנה
══════════════════════════════════════

שום דבר חדש. שולף מטבלאות קיימות:
- tasks (assigned_to, status, due_date, project_id, google_task_id)
- daily_tasks (user_email, title, due_date, status, project_id)
- projects (default_assignee, name, status)
- google_task_tokens (user_email, refresh_token, task_list_id)

שדה חדש אחד: google_task_id ב-daily_tasks (לסנכרון יומיומיות לגוגל)
